# 進捗記録 2026/07/21

## 本日の目標

Spring Bootによるバックエンド環境を構築し、最初のGET APIからJSON形式のミッションデータを返せるようにする。

## 実装した内容

### Spring Bootプロジェクトの作成

Mission Board直下へ`backend`フォルダを追加し、IntelliJ IDEAからSpring Bootプロジェクトを作成した。

今回使用した主な構成は以下。

- Java 25
- Eclipse Temurin 25.0.3 LTS
- Spring Boot 4.1.0
- Maven
- Spring Web
- 組み込みTomcat
- IntelliJ IDEA

現時点ではデータベース関連の依存関係は追加せず、REST APIの作成に必要な`Spring Web`のみ導入した。

### Spring Bootの起動確認

`BackendApplication`を実行し、以下のログが表示されることを確認した。

```text
Tomcat started on port 8080
Started BackendApplication
```
