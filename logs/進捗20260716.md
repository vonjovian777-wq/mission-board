## ミッション達成状態の切り替え

ReactのuseStateを使用して、
ミッション一覧を画面上の状態として管理した。

ボタンを押すことで、
対象ミッションのcompletedを切り替えられるようにした。

```text

↓
達成済み
↓
未達成へ戻す
```

状態変更に合わせて、
以下の表示が自動で切り替わることを確認した。

- ステータス表示
- ボタンの文言
- カードの色
- EXP
- EXPゲージ

## EXP・レベル計算

達成済みミッションのrewardExpを合計し、
現在のEXPとして表示する処理を実装した。

EXPを別の状態として保持せず、
ミッション一覧から毎回計算する方式を採用した。

### 初期ルール

- レベル1から開始
- 100EXPごとにレベルアップ
- 現在EXPは100未満の余りを表示

これにより、
ミッションを未達成へ戻した場合もEXPが自動で再計算される。

```powershell

```

### 対話式rebase

過去のコミットメッセージを変更する方法として、
対話式rebaseを確認した。

```powershell
git rebase -i HEAD~3
```

操作確認中にrebase状態が残ったため、
以下のコマンドで開始前の状態へ戻した。

```powershell
git rebase --abort
```

最終的にローカルのmainとorigin/mainが
同じコミットを参照していることを確認した。

# 本日学んだこと

## Viteの役割

ViteはIDEではなく、
Reactアプリの作成・開発サーバー起動・ビルドを行う開発ツール。

Visual Studio Code上でコードを編集し、
Viteの開発サーバーを起動した状態で保存すると、
変更内容がブラウザへ即時反映されることを確認した。

---

## JSXとTSX

JSXはJavaScript内へHTMLに似た構文を記述する仕組み。

TSXはTypeScript内でJSXを使用するファイル形式。

記述したTSXはViteなどによって、
ブラウザで実行可能なJavaScriptへ変換される。

---

## Reactの状態管理

useStateで管理している値を更新すると、
Reactが関連する表示を再計算して画面へ反映する。

個別の画面要素を直接書き換えるのではなく、
状態に応じた表示内容を宣言する考え方を確認した。

---

## 配列処理

ミッション一覧の更新にmapを使用し、
達成済みEXPの合計にreduceを使用した。

```text
map
→ 各ミッションを確認し、対象データを更新

reduce
→ 達成済みミッションのEXPを合計
```

---

## Git履歴の修正

```text
最新コミットを修正
→ git commit --amend

複数前のコミットを修正
→ git rebase -i

進行中のrebaseを取り消す
→ git rebase --abort
```

Git操作中は、
git statusで現在の状態を確認することが重要だと学んだ。
